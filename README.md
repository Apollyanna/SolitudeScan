# SolitudeScan

Plataforma de leitura de Manhwas, Mangas e Manhuas.

Site: https://rine-gumdrop-b81e47.netlify.app

## Como popular o catalogo (obrigatorio)

1. Abra https://supabase.com/dashboard
2. SQL Editor -> New query
3. Cole o arquivo `COLE_ISTO_NO_SUPABASE.sql`
4. Clique em RUN
5. Atualize o site (F5)

## Arquivos importantes

- `COLE_ISTO_NO_SUPABASE.sql` - seed de obras de teste
- `PASSO_A_PASSO.txt` - instrucoes simples
- `GUIA_APK_E_BANCO.md` - guia APK e banco
- `capacitor.config.json` - config para app Android

## Stack

HTML + CSS + JS + Supabase + PWA + Netlify
